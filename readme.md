# 🛒 Nexus E-commerce

**Nexus** is a full-stack e-commerce platform for selling all brands of smartwatches online. It features a user-friendly interface, admin dashboard, secure payments, and robust authentication systems.

---

## 🚀 Tech Stack

- **Backend**: Node.js, Express.js
- **Database**: MongoDB (Mongoose)
- **Templating Engine**: EJS
- **Frontend**: Bootstrap, jQuery, Cropper.js
- **Authentication**: Session-based Auth, Google OAuth
- **Payment Gateway**: Razorpay
- **File Export**: Excel & PDF (Sales Reports)

---

## 🔐 Features

### 👥 User Side
- Register/Login (with Google OAuth)
- Browse smartwatches by brand
- Add to Cart & Wishlist
- Apply Coupons
- Checkout via Razorpay or Wallet
- View Orders & Invoices
- Edit Profile with Cropper.js (image cropping)

### 🛠️ Admin Side
- Admin Authentication
- Dashboard Overview
- Manage Products, Brands, Categories
- Manage Users, Orders, Coupons
- View Sales Reports (PDF & Excel)
- Wallet and Refund Management
